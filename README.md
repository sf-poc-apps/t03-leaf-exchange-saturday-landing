# Leaf Exchange Saturday

A one-page static site for a neighbourhood plant swap. It tells neighbours when and where the event happens (Saturday, 10:00, Community Garden), how the swap works in 3 steps, shows 8 example plant cards, answers common questions in an expandable FAQ, and includes a "What to bring" checklist whose ticks are saved in the browser via `localStorage`. No backend, no accounts, no tracking.

## Use it

- Local preview: `python3 -m http.server -d public 8000` then open http://localhost:8000
- Docker: `docker build -t app . && docker run -p 8080:8080 -e PORT=8080 app` (health endpoint at `/healthz`)
- Tick items in "What to bring" and reload the page — your ticks persist in the same browser. Use "Reset checklist" to clear them.

## Develop

- Plain HTML/CSS/vanilla JS in `public/` — no build step, no frameworks, no external assets.
- Run tests: `python -m pytest -q` and `node tests/page.test.js`
- Policy scan: `python3 .sf/policy_scan.py` (must report zero findings)
